# Персональное портфолио

Одностраничный сайт-портфолио на React + TypeScript + Vite в редакционной стилистике.
Белый фон, ярко-алый акцент, крупная типографика, асимметричная сетка.

## Команды

```bash
npm install     # зависимости
npm run dev     # локальный сервер
npm run build   # проверка типов и production-сборка
npm run preview # просмотр собранной версии
```

## Структура

```
design/                  дизайн-система: токены, компоненты, движение, производительность
src/
  assets/work/           обложки проектов (демонстрационные SVG)
  components/
    layout/              Header, Footer
    sections/            Hero, SelectedWork, About, Services, Contact
    ui/                  Button, SectionHeading
    work/                ProjectTile
  data/site.ts           весь контент сайта
  lib/useReveal.ts       reveal-слой на IntersectionObserver
  styles/                токены, базовые стили, layout-утилиты
```

## Контент

Весь текст, ссылки и проекты лежат в `src/data/site.ts`.
Тексты демонстрационные: замените имя, специализацию, город, email, проекты,
услуги и ссылки на свои. Компоненты менять не нужно.

Обложки проектов — `src/assets/work/work-01..04.svg`.
Замените файлы на реальные изображения (WebP/AVIF), сохранив пропорции 4:3 или 3:2.

## Дизайн-система

Источник правил — `AGENTS.md` и `design/*.md`.
Цвета и шрифт не меняются: белый фон, алый `#EF3347`, системный гротеск.

## Анимации

- Hero: один CSS-вход `hero-enter` с задержками 0/70/150 мс.
- Заголовки секций: GSAP-подъём с маской, по словам, один раз.
- Reveal-блоки: `useReveal` + `ScrollReveal`, задержки 0/60/120/180 мс.
- Email: blur-scrub по скроллу.
- Меню: GSAP-таймлайн, около 0,45 с, с ловушкой фокуса.
- `prefers-reduced-motion: reduce` отключает движение и blur.

## Производительность

- Нет внешних шрифтов: только системный гротеск.
- Все изображения ниже первого экрана с `loading="lazy"` и заданными размерами.
- Нет горизонтальной прокрутки на 320–1440 px.
- Бандл: около 132 КБ gzip JS и 4,2 КБ gzip CSS (GSAP + ScrollTrigger).
- Один шрифт, системный стек, без внешних запросов.
