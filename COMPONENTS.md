# COMPONENTS

Библиотека компонентов проекта. Состав, состояния, правила использования.

## Структура компонента

Каждый компонент описывается по шаблону:

- Назначение — какую задачу решает.
- Анатомия — из каких частей состоит.
- Состояния — `default`, `hover`, `focus`, `active`, `disabled`, `loading`, `error`.
- Слоты — что можно передать внутрь.
- Токены — какие токены используются.
- Доступность — роли, клавиатура, фокус.

## Перечень

| Компонент | Назначение | Состояния | Статус |
| --- | --- | --- | --- |
| Button | Действия | все базовые | — |
| Input | Ввод текста | все базовые | — |
| Select | Выбор из списка | все базовые | — |
| Checkbox | Множественный выбор | все базовые | — |
| Switch | Двоичное переключение | все базовые | — |
| Card | Группировка контента | `default`, `hover` | — |
| Modal | Отдельное окно | `open`, `closing` | — |
| Toast | Краткие уведомления | `info`, `success`, `error` | — |
| Tabs | Переключение разделов | `default`, `active` | — |
| Table | Табличные данные | `default`, `empty`, `loading` | — |

## Правила

- Компонент не содержит внешних отступов: расстояние задаёт родитель.
- Один компонент — одна задача. Составные части собираются композицией.
- Все состояния обязательны. Нет состояния — нет компонента в библиотеке.
- Стили на токенах. Прямые значения не допускаются.
- Клавиатура и фокус работают до проверки внешнего вида.
